RH Freemint Hunter

Automatic NFT mint hunter for Robinhood Chain

User manual · Version 1.0

1. What this program does

It watches for new NFT collections launching on Robinhood Chain and mints the ones worth having, automatically. Some free mints sell out within minutes, which is why a program does this better than a person watching a screen.

It follows the same four steps every time:

Find new and upcoming drops | Decide whether each one qualifies | Check you have not already minted it | Mint one, and write down what happened
It starts in Practice Mode

The program does everything except actually spend money. You can run it, watch it work, and understand it before any real money is involved.

2. Installing it

There is no installer. Put RH-Freemint-Hunter.exe in a folder of its own — for example Documents\NFT Hunter\ — and double-click it.

Your web browser opens the dashboard automatically. Nothing else appears - there is no console window to leave open.

"Windows protected your PC"

Windows shows this for any program it has not seen before. It is not a virus warning. Click More info, then Run anyway.

How to close it

Use the Quit app button at the top right of the dashboard. Closing the browser tab does not stop the program - the browser is only a remote control, and the bot keeps running behind it.

4. The rules it follows

Is the mint free? | YES --+-- always qualifies | NO --+-- qualifies only if BOTH: credibility score is 75 or higher price is under your limit

What the credibility score means

A number out of 100, worked out from things the program can verify itself on the blockchain:

  • Has the project published its contract code for anyone to inspect?
  • Does it have proper artwork and description set up?
  • Are creator royalties configured?
  • Does it have real holders, or nobody?
  • Is the collection size sensible?
  • Is the mint window a reasonable length?
  • Is the name a placeholder like "test"?

A serious project scores high. A thrown-together scam scores low.

Free mints skip the score on purpose

A free mint costs only the transaction fee — under one cent. The score exists to protect you from paying for something worthless, so it is not applied when nothing is being paid.

Changing the rules

On the Dashboard tab there is a slider for the score and a box for the price limit. As you move them, a line underneath tells you what would change, based on drops it has already seen — so you can see the effect before committing.

Nothing is saved until you press Apply new rules.

SettingGuidance
Minimum credibility75 is a sensible start. Below 60 starts letting in unverified projects with no real holders.
Max price per mintYour real spending protection. Keep it low. Set it to 0 for free mints only.

5. Using your own currency

Under Settings → Rules → Currency there are 35 currencies, including Sri Lankan Rupee, Indian Rupee, Euro, Pound and Dirham.

When you change currency, your price limit is converted automatically so it stays worth the same amount. A limit of $1 becomes about Rs 332 — not "1 rupee". A line under the dropdown shows the new figure before you save.

6. Using it with real money

Take these in order. Do not skip step 3.

  1. Make a burner wallet. A brand-new wallet used only for this program. Never your main wallet.
  2. Put a small amount in it. 0.001 ETH on Robinhood Chain is about $2 and covers roughly 200 mints. This is the most you can lose.
  3. Watch it in Practice Mode first. With money in the wallet but Practice Mode still on, the program does everything short of sending. If the Activity tab shows lines beginning [DRY RUN] would mint, then everything works.
  4. Then go live. Press Stop. In Settings, untick Practice Mode. Save. Press Start hunting. The bar turns red.
Sensible limits for your first live run

Max price per mint 0 (free only) · Max mints per run 1 · Gas budget 0.0005 ETH

It will mint exactly one free NFT and stop, so you can check the result before letting it run freely.

Please read this once

This program spends real money without asking each time — that is the whole point of it. Your protection is the limits you set, and the burner wallet holding only what you can afford to lose.

A free mint still costs a transaction fee, and the NFT it collects may turn out to be worth nothing. Nobody can promise otherwise.

7. Running it in the background

Once you trust it, double-click Start-Hidden.vbs instead of the .exe. The program runs invisibly — no black window at all.

To close it then, use the Quit app button on the dashboard. That is the only way to stop it when there is no window.

Starting it automatically when the computer turns on

  1. Press Windows key + R
  2. Type shell:startup and press Enter
  3. Put a shortcut to Start-Hidden.vbs into the folder that opens

9. Keeping yourself safe

  • Stay in Practice Mode until you understand what it does.
  • Use a burner wallet with small amounts. Never your main wallet.
  • Your .env file contains your private key. Anyone who gets it controls that wallet. Never send it to anyone, and never post a screenshot of the Settings page.
  • The dashboard is only reachable from your own computer. Keep it that way.
  • hunter.log records what the program did. It contains no keys, so it is safe to share when asking for help.
  • Keep the price limit low. It is what stands between you and an expensive mistake.
